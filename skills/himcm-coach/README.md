# HiMCM modeling coach

[中文说明](README.zh-CN.md)

An instruction-only coaching skill for HiMCM problem framing, explainable high-school-level models, validation, sensitivity analysis and academic writing. It routes specialized analyses and LaTeX formatting to complementary skills. It checks current contest rules before assistance in an active competition.

The reference guide distills selected user-supplied lessons and contest commentary, identifies known errors and acknowledges incomplete PDF extraction. It does not include the original PDFs, provide an official rubric, guarantee awards, or establish that every source page was read. Install the complete folder in a personal Codex skills directory. Automatic selection is enabled by default but is not guaranteed in every conversation; users can explicitly invoke `$himcm-coach`.
