# HiMCM LaTeX 规则适配

[English](README.md) · 简体中文

这是指令型技能，将已有 MCM/ICM 英文 LaTeX 项目适配到 HiMCM：摘要页、至少12磅字体、页眉、匿名、25页解答检查及另附的 AI 使用报告。当届官方规则优先于附带的2026年规则记录。

把本目录复制到智能体技能目录，提供英文论文项目及可用编译器、PDF检查工具。可选配单独安装的 [mathmodel-latex-skill](https://github.com/wangling-miao/mathmodel-latex-skill)。本目录不转载原仓库模板或脚本；核查时原仓库没有许可证。本技能独立维护，未获 COMAP 背书。

示例：“使用 himcm-latex-profile，按当届HiMCM规则适配这份英文论文，显式检查解答部分不超过25页。”

AI报告不计入解答页数，但最终合并在同一个PDF中。当前发布验证了技能结构和规则工作流，实际论文仍需编译并逐页检查；尚未验证具体HiMCM论文编译样例或官方摘要页的精确还原。
