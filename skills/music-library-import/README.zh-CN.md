# 专辑下载与 Apple Music 导入

[English](README.md) · [简体中文](README.zh-CN.md)

本技能用于从用户提供的网站或其他合法下载来源获取指定专辑，对照用户声明的目标音质核验实际音频格式，确认版本与曲目清单，将文件整理到 iCloud Drive，并通过 Apple Music 正常导入。

除非用户已经说明，否则搜索前先询问目标音质。优先选择有授权的无损下载，并检查文件真实属性，不只相信网页标签。若 Music 需要 ALAC 副本，则保留下载原件。绝不绕过 DRM、口令、验证码、付费墙或其他访问控制，也不抓取流媒体。无痕窗口只用于排查普通会话或缓存故障，不可用于绕开访问控制。购买前必须向用户确认价格。

完成前核实 Music 资料库中的专辑、艺人、曲目数和顺序。分别报告文件在本机 iCloud Drive 中的位置及云端同步状态；音讯分析或同步仍在等待时，不得称其已完成。
